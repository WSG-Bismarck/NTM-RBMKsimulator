# RBMK 反应堆模拟器

《我的世界》1.7.10 **HBM 核科技（HBM's Nuclear Tech）** 模组的 RBMK 反应堆桌面模拟器。

俯视网格搭建堆芯，实时模拟「堆芯 → 蒸汽 → 汽轮机发电」整条链路，数值与机制按模组 jar 反编译逐项还原。

## 功能

- **18 种反应堆组件、34 种燃料**，名称取自模组 `zh_CN.lang`
- **完整发电链**：柱温 → 蒸汽 → 逐级降温 → 汽轮机 → HE
- **四种蒸汽**：蒸汽 / 热蒸汽 / 超热蒸汽 / 超浓密蒸汽，支持 ReaSim 锅炉模式
- **控制棒**：全局 / 5 色分组 / 单根三种调法，支持空置与自动控制棒（温度区间 + 曲线）
- **汽轮机配置**：每个蒸汽降温阶段可选工业汽轮机或利维坦巨型汽轮机，并按模组输出上限计算所需台数
- **可视化**：模组控制台式柱状叠加显示、鼠标悬停信息、实时曲线、9 项关键指标
- **风险预警**：柱温 / 壳温双规则熔毁判定，预计安全运行时长倒计时
- **存档分享**：JSON 设计文件，跨玩家可直接打开

## 运行

直接双击 `dist/RBMK-Simulator.exe`（Windows 10/11，无需安装 Python）。

从源码运行：

```
pip install -r requirements.txt
python main.py
```

跑测试与打包：

```
python -m pytest -q
build.bat
```

## 数值保真度

- 已还原：组件与燃料清单、燃料逐项数值、反应性 / 氙毒公式、热链与 tick 执行顺序、蒸汽管道与 ReaSim 锅炉、冷却器、控制棒、汽轮机换算。
- 仍为模型层参数：全局中子通量标度、部分热工系数、蒸汽与水的罐容量（模型不设蒸汽缓冲，产汽即时外送）。
- 详细对照见 [spec/rbmk-mechanics.md](spec/rbmk-mechanics.md)。

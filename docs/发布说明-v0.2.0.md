# RBMK 反应堆模拟器 v0.2.0

《我的世界》1.7.10 **HBM 核科技（HBM's Nuclear Tech）** 模组的 RBMK 反应堆桌面模拟器首个公开版本。

## 主要功能

- **18 种反应堆组件、34 种燃料**，名称与数值取自模组 jar
- **完整发电链**：柱温 → 蒸汽 → 四级降温 → 汽轮机 → HE
- **四种蒸汽**（蒸汽 / 热蒸汽 / 超热蒸汽 / 超浓密蒸汽）与 ReaSim 锅炉模式
- **控制棒**：全局 / 5 色分组 / 单根三种调法，支持空置与自动控制棒
- **汽轮机配置**：每个蒸汽降温阶段可选工业汽轮机或利维坦巨型汽轮机，自动计算所需台数
- **可视化**：模组控制台式柱状叠加显示、鼠标悬停信息、实时曲线、9 项关键指标
- **风险预警**：柱温 / 壳温双规则熔毁判定与预计安全运行时长
- **存档分享**：JSON 设计文件，跨玩家可直接打开

## 安装

1. 下载本页附件的 zip
2. 解压到任意目录
3. 双击 `RBMK-Simulator.exe`（Windows 10/11 64 位，无需安装 Python）

## 已知限制

- 蒸汽罐、水罐为模型层简化，模型不设蒸汽缓冲，产汽即时外送
- 全局中子通量标度与部分热工系数尚未对齐 `RBMKDials` 默认值
- 利维坦汽轮机的 85% 效率为玩家实测稳态值，非模组常量
- 仅提供 Windows 版本

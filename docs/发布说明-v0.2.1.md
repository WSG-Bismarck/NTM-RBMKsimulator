# RBMK 反应堆模拟器 v0.2.1

《我的世界》1.7.10 **HBM 核科技（HBM's Nuclear Tech）** 模组的 RBMK 反应堆桌面模拟器。

本版为 v0.2.0 之后的修复与增强版。

## 本版更新

**控制棒**

- 属性面板「有效 level」改为「插入深度」，直接显示百分比；自动棒显示「当前插入度 / 目标」
- 控制优先级改为**后输入覆盖前输入**：全局、分组、单根各自带递增序号，最后调整的那个生效；拉一次全局即可覆盖之前设过的单根
- 新增「清除单根覆盖（跟随分组/全局）」按钮
- 修复打开属性面板或模拟控制页时会悄悄抢夺控制权的问题（Tk `Scale.set()` 会触发回调）
- 控制棒初始插入深度改为 0%（完全抽出）
- ReaSim 控制棒标注供电需求（移动时 5,000 HE/tick，缓冲 50,000 HE）

**主界面**

- 控制棒插入条方向修正：插入越深条越长
- 切换蒸汽类型后网格立即重绘
- 辐照通道新增「接收通量 / 快中子计数 / 慢中子计数」，属性面板与悬停提示同步显示；引擎按 `IRBMKFluxReceiver` 累计通量且中子继续穿过

**界面与文档**

- 界面改为《我的世界》原版灰石风格（面板、按钮、槽位立体边框，曲线使用原版聊天栏配色）
- 工具栏新增「使用说明」，弹窗显示《快速上手》全文
- 鼠标悬停组件显示名称、柱温、燃料/控制棒/蒸汽等关键信息，每 100ms 刷新
- 底部指标扩为 9 项（平均温度、表面温度、插入深度、蒸汽产量 mB/tick、瞬时/累计发电、燃料寿命、氙中毒、中子通量）
- 总览新增汽轮机配置：按 4 个蒸汽降温阶段选择工业/利维坦汽轮机，自动计算所需台数，利维坦按 85% 计入发电量
- 速度栏新增自定义倍数输入（1 ~ 1,000,000x）
- 仓库以 GPL-3.0 开源，`docs/` 收录设计文档

## 安装

1. 下载本页附件的 zip
2. 解压到任意目录
3. 双击 `RBMK-Simulator.exe`（Windows 10/11 64 位，无需安装 Python）

## 已知限制

- 蒸汽罐、水罐为模型层简化，模型不设蒸汽缓冲，产汽即时外送
- 全局中子通量标度与部分热工系数尚未对齐 `RBMKDials` 默认值
- 利维坦汽轮机的 85% 效率为玩家实测稳态值，非模组常量
- 辐照通道仅统计接收通量，尚未模拟辐照产物进度
- 仅提供 Windows 版本

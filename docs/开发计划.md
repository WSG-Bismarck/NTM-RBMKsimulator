# RBMK 反应堆模拟器 — 开发计划

> 依据：PRD.md（v1.2）
> 日期：2026-10-20
> 原则：先搭 UI 骨架（不依赖 jar），再解包 jar 提取机制与数值，最后接真实模拟引擎。jar 是唯一阻塞点，其余阶段可并行推进。

---

## 0. 技术选型与总体架构

### 0.1 技术栈（由开发者选定，用户无需关心实现）
| 项 | 选择 | 理由 |
|---|---|---|
| 语言/框架 | Python 3.11+ + **PySide6**（Qt） | 成熟桌面框架、原生 Windows 窗口、适合网格编辑器 |
| 实时曲线 | **pyqtgraph** | 高倍速下实时刷新性能好 |
| 打包 | **PyInstaller** → 单个 `.exe` | 用户双击即用，无需安装 Python |
| 保存格式 | **JSON** | 通用、可移植、便于分享与再编辑 |
| 单元测试 | pytest | 引擎对照测试 |
| jar 反编译 | Vineflower / CFR | 提取模组的组件、燃料、机制与数值 |

### 0.2 架构原则
1. **UI 与引擎解耦**：模拟引擎（纯计算，不碰界面）与界面分开，引擎可单独用 pytest 测试、单独对照 jar 数值。
2. **数据来自 jar 规格**：组件清单、燃料清单、数值常量、公式，全部从 `spec/rbmk-mechanics.md`（阶段 1 产出）读取，不硬编码、不自行假设。
3. **设计文件自描述**：JSON 里带版本号，方便以后升级兼容。

## 2. 各阶段详细任务（可直接执行）

### 阶段 0：环境与项目骨架
- [ ] 0.1 确认本机 Python ≥ 3.11（`python --version`）
- [ ] 0.2 创建虚拟环境并安装依赖：`pip install PySide6 pyqtgraph pytest pyinstaller`
- [ ] 0.3 生成 `requirements.txt`（锁定版本）
- [ ] 0.4 创建 0.3 节目录结构，git 初始化
- [ ] 0.5 写 `src/main.py` 显示一个空白窗口（冒烟测试）
**交付**：能运行出一个空白窗口；依赖已锁定。

### 阶段 1：jar 分析（关键路径，拿到 jar 立即启动）
- [ ] 1.1 记录 jar 的**完整文件名/版本号**（确认是 1.7.10 的哪个分支）
- [ ] 1.2 解压 jar（本质是 zip），用 `rg -i rbmk` 找出所有 RBMK 相关 `.class`
- [ ] 1.3 用 Vineflower/CFR 反编译相关类，重点找：反应堆 tick 逻辑、燃料棒、控制棒、锅炉/蒸汽、燃料消耗、熔毁判定
- [ ] 1.4 提取三份数据：
  - ① **组件清单**（柱子类型及注册枚举）
  - ② **燃料类型清单**（燃料种类 + 富集度 + 各自属性）
  - ③ **机制与数值**（每 tick 的中子通量/热/控制棒反应性/燃料消耗/蒸汽/熔毁阈值公式与常量）
- [ ] 1.5 写成 `spec/rbmk-mechanics.md`（机制 + 数值规格，作为引擎唯一依据）
**交付**：`spec/rbmk-mechanics.md`，组件/燃料/机制三份清单齐全，关键公式与常量抽样核对无误。
**阻塞说明**：阶段 4、5 依赖本阶段产出。

### 阶段 2：界面框架（可并行，不依赖 jar）
- [ ] 2.1 主窗口 6 区域布局（工具栏/组件栏/网格画布/属性面板/曲线图/状态栏），对齐原型
- [ ] 2.2 组件栏：先放占位清单（8 种柱子 + 选择/擦除），后续由 spec 替换
- [ ] 2.3 网格画布：单击放置、拖动连续放、右键删、选择、滚轮缩放、拖拽平移
- [ ] 2.4 属性面板 4 标签页：选中属性 / 反应堆总览 / 模拟控制 / 风险预警（先用占位数据）
- [ ] 2.5 曲线图（温度/功率/中子通量）+ 6 项关键数值 + 状态栏
- [ ] 2.6 速度档位（暂停/1x/10x/100x/1000x）+ 运行/暂停，接一个**假数据 ticker** 验证 UI 联动
- [ ] 2.7 控制棒的全局调节 + 单根/分组调节的**交互骨架**（接占位数据，真实逻辑等阶段 4）
**交付**：界面与原型一致、可交互、用占位数值跑通。
**对应验收**：A1~A5、B1~B2（B3/B4 待阶段 4 接真引擎）。

### 阶段 3：数据模型与保存/导出（不依赖 jar）
- [ ] 3.1 定义设计文件 JSON schema：网格尺寸、每格（类型 + 参数）、全局设置、`version` 字段
- [ ] 3.2 实现保存 / 打开 / 导出 / 导入（`save_load.py`）
- [ ] 3.3 往返一致性测试：保存 → 重开，布局与参数完全一致
- [ ] 3.4 schema 预留「燃料/组件参数」扩展位，便于阶段 4 用 spec 填充
**交付**：`save_load.py` + 往返测试通过。
**对应验收**：C1（C2 跨机验证放阶段 6 打包后做）。

### 阶段 4：模拟引擎（依赖阶段 1）
- [ ] 4.1 按 `spec/rbmk-mechanics.md` 实现中子学（`neutronics.py`）
- [ ] 4.2 实现热/蒸汽/涡轮/冷凝（`thermal.py`）
- [ ] 4.3 实现燃料消耗与剩余寿命
- [ ] 4.4 控制棒：**全局统一** + **单根/分组**两种调节（对应 B4）
- [ ] 4.5 tick 调度：暂停/1x/10x/100x/1000x，引擎与 UI 解耦（纯计算可独立跑）
- [ ] 4.6 单元测试 + 与 spec 数值**抽样比对**（差异要有说明）

**交付**：`engine.py` + 测试通过；UI 接真引擎；B3/B4、D1~D3 通过。

### 阶段 5：风险预警（依赖阶段 1/4）

- [ ] 6.3 PyInstaller 打包成单文件 `.exe`
- [ ] 6.4 按 PRD 验收标准 A~E 逐条自测并记录结果

## 5. 风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| jar 迟迟不传 | 阶段 4/5 无法开工 | 阶段 0/2/3 先做，界面+保存提前完成 |
| 反编译出的代码混淆/难读 | 提取机制耗时 | 先按类名/常量定位，必要时参考模组 wiki/源码仓库交叉核对 |
| 模组为立体结构，俯视网格映射复杂 | 画布模型不准 | 阶段 1 明确柱子俯视占位规则，写入 spec；必要时先做「单层横截面」再扩展 |
| 高倍速下性能 | 1000x 卡顿 | pyqtgraph + 引擎与渲染解耦，tick 批处理 |
| 数值「完全还原」难以百分百 | 验收 D3/E3 有差异 | 抽样比对 + 差异说明；与用户确认可接受偏差范围 |
